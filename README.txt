Экран U613 — чёрный «циферблат» с одной кнопкой, которая открывает таймер. ЭКСПЕРИМЕНТАЛЬНО.
Сборка и установка — так же, как таймер: отдельный публичный репозиторий на GitHub, файлы из этой папки в корень,
GitHub Actions соберёт, QR-код в Releases, сканировать в Zepp (режим разработчика). После установки:
часы -> долгое нажатие на экран -> выбрать «Экран U613» как циферблат.
Если кнопка не открывает таймер — это ограничение Zepp для чужих приложений; тогда этот экран остаётся просто чёрным,
а таймер открывается из списка приложений.
